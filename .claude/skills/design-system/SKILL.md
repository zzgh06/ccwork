# design-system

스타일 작업 전 디자인 시스템 규칙을 로드하고, 작업 대상 파일의 현재 상태를 점검한 뒤 규칙 준수 상태로 작업을 진행한다.

## 실행 절차

### 1. 디자인 시스템 파일 로드

다음 세 파일을 순서대로 읽는다.

| 파일                               | 목적                                     |
| ---------------------------------- | ---------------------------------------- |
| `docs/design-system/rules.md`      | Do/Don't 전체 규칙 — 절대 위반 금지 목록 |
| `docs/design-system/tokens.md`     | 색상·간격 토큰 — 실제 값 참조            |
| `docs/design-system/components.md` | 버튼·카드·Input·Chip 구현 패턴           |

필요 시 `docs/design-system/typography.md`도 읽는다 (텍스트 스타일링 작업일 때).

### 2. 작업 대상 파일 선제 점검

작업할 파일을 읽고 다음을 확인한다.

- `bg-white`, `text-black`, `#000000` 등 금지 클래스/값 사용 여부
- `border-*` 클래스로 영역 구분하고 있는지
- `box-shadow` 기본값 사용 여부
- 토큰 색상값 대신 임의 색상값 사용 여부

위반 사항이 있으면 작업 전 사용자에게 알린다.

### 3. 규칙 준수 상태로 작업 진행

로드한 규칙을 적용하여 작업을 수행한다.

- 색상은 반드시 토큰 색상값(`#f8f9fa`, `#2b3437` 등) 사용
- 영역 구분은 배경색 전환으로만 처리
- 카드·목록 구분선 대신 `gap: 1.4rem` 사용
- Primary 버튼에만 `tertiary` 그라디언트 적용

### 4. 완료 후 요약

작업 완료 후 다음을 간단히 보고한다.

- 적용한 토큰 색상값 목록
- 준수한 주요 규칙 항목
- 추가 검수가 필요하면 `/design-check` 사용 안내
