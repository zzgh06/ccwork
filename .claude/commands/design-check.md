# /design-check

디자인 시스템 규칙 기준으로 파일의 스타일 위반 사항을 종합 검수한다.

## 실행 방법

- `/design-check` — 최근 수정 파일 자동 감지 후 검수
- `/design-check src/components/NoteItem.tsx` — 특정 파일 지정 검수
- `/design-check src/components/` — 디렉토리 내 전체 .tsx/.css 파일 검수

## 실행 절차

### 1. 규칙 로드

`docs/design-system/rules.md`를 읽어 Do/Don't 전체 목록을 로드한다.

### 2. 대상 파일 읽기

인수로 파일이 지정된 경우 해당 파일을 읽는다.
지정되지 않은 경우 `git diff --name-only HEAD`로 최근 수정 파일 목록을 확인하고
`.tsx` / `.css` 파일만 대상으로 한다.

### 3. 위반 항목 탐지

각 파일에서 다음 패턴을 검사한다:

| 패턴                | 규칙 위반                      | 수정 방향                                      |
| ------------------- | ------------------------------ | ---------------------------------------------- |
| `bg-white`          | Tailwind 기본 색상 클래스 금지 | `#ffffff` (surface_container_lowest) 토큰 사용 |
| `text-black`        | Tailwind 기본 색상 클래스 금지 | `#2b3437` (on_surface) 사용                    |
| `#000000`           | 순수 검정 텍스트 금지          | `#2b3437` 사용                                 |
| `border-[a-z]`      | border로 영역 분리 금지        | 배경색 전환으로 구분                           |
| `box-shadow` 기본값 | 기본 shadow 금지               | Ambient Shadow 규격 적용                       |
| `divide-`           | 목록 구분선 금지               | `gap: 1.4rem` 사용                             |

### 4. 리포트 출력

위반 항목을 다음 형식으로 출력한다:

```
파일명:줄번호 — [위반 규칙] — 수정 제안
```

위반이 없으면 "디자인 시스템 규칙 통과" 메시지를 출력한다.

### 5. 수정 진행 여부 확인

위반 항목이 있을 경우 사용자에게 수정 진행 여부를 묻는다.
승인 시 각 위반 항목을 올바른 토큰 값으로 수정한다.
