# 태그 기능 정의서 (확정)

## 기능 개요

노트에 태그를 추가하고 관리할 수 있다.

## 기능 요구사항

- 노트에 태그를 추가할 수 있다
- 노트에 추가된 태그를 삭제할 수 있다
- 태그 목록을 노트 편집 화면(NoteEditor)과 노트 목록 카드(NoteItem)에서 확인할 수 있다

## 데이터 구조

태그는 노트 객체 내부의 문자열 배열로 저장한다.

```json
{
  "id": "1",
  "title": "노트 제목",
  "content": "내용",
  "tags": ["React", "TypeScript"],
  "createdAt": "...",
  "updatedAt": "..."
}
```

- `tags` 필드는 `string[]` 타입
- `Note` 인터페이스에 `tags: string[]` 추가
- 별도 컬렉션 분리 없음

## UI 패턴

### 태그 입력 (NoteEditor)

- 태그 칩(chip) + 입력창 형태로 표시
- 입력창에 태그 텍스트 입력 후 **Enter** 키로 추가
- 추가된 태그는 `[태그명 ×]` 형태의 칩으로 표시
- 칩의 `×` 버튼 클릭 시 해당 태그 제거
- 태그는 노트 **저장 버튼 클릭 시** 함께 저장 (즉시 저장 아님)

### 태그 표시 (NoteItem)

- 노트 목록 카드 하단에 태그 칩 목록 표시 (읽기 전용)
- 태그가 없으면 해당 영역 미표시

## 유효성 검사

| 항목           | 규칙                                                    |
| -------------- | ------------------------------------------------------- |
| 최대 길이      | 20자 이내                                               |
| 공백 처리      | 입력값 앞뒤 trim 후 처리                                |
| 빈 값          | trim 후 빈 문자열이면 추가 무시                         |
| 중복           | 대소문자 구분 없이 비교, 중복이면 무시 (에러 표시 없음) |
| 허용 문자      | 별도 제한 없음                                          |
| 노트당 태그 수 | 제한 없음                                               |

## 태그 순서

- 사용자가 입력한 순서를 유지한다

## 저장 흐름

```
사용자 입력 (Enter)
  → 로컬 상태(tags 배열)에 추가
  → 저장 버튼 클릭
  → updateNote({ ...note, tags }) API 호출
  → Context 상태 갱신
```

## 타입 변경

`src/types/note.ts`의 `Note` 인터페이스에 `tags` 필드 추가:

```ts
export interface Note {
  id: string;
  title: string;
  content: string;
  tags: string[];
  createdAt: string;
  updatedAt: string;
}
```
