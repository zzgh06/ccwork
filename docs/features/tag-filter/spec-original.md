# 태그 필터링 — 초기 아이디어

## 아이디어 요약

노트 목록을 태그 기준으로 필터링하는 기능을 추가한다.
사용자가 특정 태그를 선택하면, 그 태그를 가진 노트만 사이드바에 표시된다.

## 배경

- TAG-1 ~ TAG-4 완료로 노트에 태그 부착 및 NoteItem 칩 표시가 가능해졌다.
- 태그 기반 필터링은 tag PRD의 Out of Scope 항목이었으며, 이번 요청으로 새 feature로 분리한다.

## 미결정 사항 (인터뷰 필요)

- 필터 진입 방식: 별도 UI? 칩 클릭?
- 다중 태그 선택 시 AND/OR
- 필터 해제 방법
- "검색어 없음" 빈 상태 처리
